# Проект интернет-магазина 

На данный момент пока в разработке, однако backend практически написан, frontend в разработке.

## Backend

- NestJS
- TypeORM
- PostgreSQL

### Запуск

1. `npm install`
2. `npm run start:dev`

## Главный сайт для покупателей Frontend

- Angular (SPA)

### Запуск

1. `npm install`
2. `npm run start`

## Сайт управления магазином Frontend

- Angular (SSR)

### Запуск

1. `npm install`
2. `npm run start`
